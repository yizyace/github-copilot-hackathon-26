# Planning Docs

This folder holds the planning docs for our **GitHub Copilot Hackathon 2026** project.

> **These docs will drift — that's expected.** They are living documents and the
> single source we build other artifacts from: the website, the pitch slides, and
> the project README. When in doubt, update the doc here first, then regenerate the
> artifact from it.

## Index

- **[project-plan.md](./project-plan.md)** — the full project plan (problem, goals, scope, milestones, roles, risks).
- **[eli5.md](./eli5.md)** — explain-it-like-I'm-5: the simplest possible description, for pitching, humans, and the website.
- **[team.md](./team.md)** — who's on the team + TODO for collecting info.

## How we use these

1. Decide or change something → update the relevant doc here.
2. Build artifacts (website copy, slides, README) *from* these docs.
3. Keep `project-plan.md` and `eli5.md` as the two anchor docs.
